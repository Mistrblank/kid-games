How does Robot decide?

Robot doesn't think like you. It follows a checklist, the same one every time, and stops at the first rule that works:

  1. Can I win right now? If one square finishes my line, take it.
  2. Do I have to block? If you're one square away from winning, block it.
  3. Can I build a line? Add to a line that has my O's and none of your X's.
  4. Is the middle free? Middle squares are part of the most lines.
  5. Nothing else? Pick any empty square.

Easy and Medium use the same checklist, but Robot sometimes "forgets" to check a rule. That's the only difference! People who write programs call a checklist like this an algorithm.
